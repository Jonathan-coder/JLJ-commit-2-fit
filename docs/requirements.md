FR-01: The user can select a product from the product database.

FR-02: The user can scan nutritional information from a product.

FR-03: The user can save a product in the central database.

FR-04: The application calculates the user's nutritional intake.

FR-05: The user can view their intake history.

FR-06: The application warns the user when their calorie or
      macronutrient intake is too low or too high.

FR-07: The user can use a fasting timer.
